        Printer didn't report much? Paste its self-test text
        
    Hold the FEED button while switching the printer on, then type or paste the values it prints (one “Name  value” per line). MyPrint reads the model, codepage, baud rate and darkness from it.
    
        
        
    
      
    
      
    
        Can't find the printer? Read this
        
      
          
    • Turn the printer on and keep it close. Do not pair it in the phone's Bluetooth settings first — choose it in the browser picker instead.
      • 
          
    • Web Bluetooth only talks to BLE devices. If the printer never shows up it is classic-only: use the desktop Bluetooth classic button, USB, or the RawBT bridge on Android.
      • 
          
    • Android / desktop: Chrome or Edge. iPhone / iPad: Safari has no Web Bluetooth — use the free Bluefy browser.
      • 
          
    • The page must be served over HTTPS (or localhost).
      • 
          
    • “BT Mul Conn: enable” — disconnect other apps (RawBT, vendor app) before connecting.
      • 
          
    • Garbled print? Set Transfer speed to Safe in Advanced settings.
