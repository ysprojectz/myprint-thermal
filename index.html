        Can't find the printer? Read this
        
      
          
    • Turn the printer on and keep it close. Do not pair it in the phone's Bluetooth settings first — choose it in the browser picker instead.
      • 
          
    • Web Bluetooth only talks to BLE devices. Your self-test says USB & Bluetooth, so the printer should advertise as BLE under a name like MPT-II, PT-210, MHT-P… or BlueTooth Printer. If it never shows up, it is classic-only: use the desktop Bluetooth classic button, USB, or the RawBT bridge on Android.
      • 
          
    • Android: use Chrome or Edge. Windows / macOS / Linux / ChromeOS: Chrome or Edge. iPhone / iPad: Safari has no Web Bluetooth — install the free Bluefy browser and open this app there.
      • 
          
    • The page must be served over HTTPS (or localhost). See the README for hosting options.
      • 
          
    • “BT Mul Conn: enable” on your printer means one phone may hold the link while another is nearby — disconnect other apps (Printer app, RawBT, etc.) before connecting.
      • 
          
    • If prints are garbled or cut off, switch Transfer speed to Safe below.
